# 端到端投资分析演示

## 概述

这个演示脚本展示了**行业先行投研系统**的完整分析能力，从数据采集到投资建议生成的全流程。

## 演示内容

### 1. 天然橡胶期货（RU2609）分析 🌾

**分析流程：**
1. ✅ 基本面数据采集（真实测试数据）
2. ✅ 供需分析（产量、库存、需求）
3. ✅ 周期判断（库存趋势、需求强度、供应状况）
4. ✅ 价格情景分析（悲观/基准/乐观）
5. ✅ 合约分析（基差、持仓量）
6. ✅ 投资建议生成
7. ✅ 跟踪指标设定

**分析结论：**
- 💡 建议：观察多单机会
- 📊 信号：库存去化 + 需求稳定 + 基差合理
- ⚠️ 风险：割胶旺季供应压力

### 2. 上海电力股票（600021.SH）分析 ⚡

**分析流程：**
1. ✅ 公司基本信息识别
2. ✅ 行业分析（公用事业-电力）
3. ✅ 公司质量分析（竞争优势、财务状况）
4. ✅ 生存能力分析（压力测试）
5. ✅ 估值分析（DDM + PE比较）
6. ✅ 投资建议生成
7. ✅ 跟踪指标设定

**分析结论：**
- 💡 建议：长期配置型资产
- 📊 特点：防御性资产，稳定分红
- ✅ 适合：低风险偏好投资者

## 系统架构示意

```
用户输入
   ↓
数据采集 → 基本面分析 → 周期/行业分析 → 估值分析
                                              ↓
风险提示 ← 跟踪指标 ← 投资建议 ← 综合判断
```

## 与系统核心模块的关系

这个演示脚本是**简化版**，展示了分析思路。实际系统使用的是更复杂的模块：

### 期货分析模块
- `futures_identity.py` - 期货身份识别
- `futures_fundamentals.py` - 基本面报告生成
- `futures_tracking.py` - 持续跟踪
- `commodity_adapters.py` - 品种适配器

### 股票分析模块
- `research_pipeline.py` - 完整研究管道
- `cycle_reversal.py` - 周期反转判断
- `survival_analysis.py` - 生存能力分析
- `valuation_scenarios.py` - 估值情景分析
- `adversarial_review.py` - 对抗审查
