# 投研分析系统 v2.0 - 使用说明

## 📋 项目简介

基于"西红柿炒鸡蛋"产业链逻辑的投资研究系统，帮助分析上市公司投资价值。

### 核心理念

用做菜的逻辑理解产业链：
- **A级（西红柿）**：核心原料，缺了做不出来
- **B级（鸡蛋）**：关键部件，重要但可能有替代
- **C级（食用油）**：重要辅料，供应商很多
- **D级（葱花）**：加分项，有更好没有也行

### 核心输出

1. **产品重要性分级**（A/B/C/D）
2. **市场地位判断**（龙头/追随者）
3. **财务健康度**（A/B/C/D评级）
4. **生存能力分析**（能撑多久）
5. **回本周期预测**（三种情景：悲观/基准/乐观）
6. **明确投资建议**（买入/观望/不买）

## 🔧 核心模块

### 1. DataCollector - 数据采集

从AKShare API实时获取：
- 股票基本信息
- 实时行情
- 财务报表（资产负债表、利润表、现金流量表）
- 分红历史
- 历史价格

**特点**：
- ✅ 实时API，不存原始数据
- ✅ 内存缓存（1小时）
- ✅ 自动重试机制

### 2. InvestmentAnalyzer - 分析引擎

实现8个分析维度：

1. **产品分析**：产业链位置、重要性分级
2. **市场地位**：市值、份额、龙头判断
3. **财务健康**：ROE、毛利率、负债率评分
4. **周期分析**：判断底部/顶部位置
5. **生存能力**：现金流、能撑多久
6. **回本周期**：三种情景预测（核心算法）
7. **投资建议**：综合评分，明确建议
8. **风险识别**：识别关键风险点

### 3. ReportGenerator - 报告生成

支持两种格式：
- **Console**：终端友好的简化报告
- **Markdown**：完整详细的分析报告

## 📊 回本周期算法（核心）

### 三种情景建模

**悲观情景（20%概率）**
```
假设：周期持续低迷，公司微利或小亏
- 分红大幅减少
- 股价下跌15%
- 3年不回本或小亏
```

**基准情景（60%概率）**
```
假设：2年内周期反转，盈利恢复
- 分红恢复到历史水平
- 股价上涨40%
- 3年回本，年化15-20%
```

**乐观情景（20%概率）**
```
假设：快速反转，份额提升
- 分红超历史水平
- 股价上涨70%
- 2年回本，年化30%+
```

### 概率加权计算

```python
期望收益 = 悲观收益 × 20% + 基准收益 × 60% + 乐观收益 × 20%
期望年化 = 期望收益 / 加权平均年限
```

## ⚙️ 配置说明

编辑 `research_system/config.py`：

```python
# 产品重要性评分权重
"importance_weights": {
    "value_ratio": 0.30,          # 价值占比
    "substitutability": 0.30,     # 不可替代性
    "market_concentration": 0.20, # 市场集中度
    "tech_barrier": 0.20,         # 技术壁垒
}

# 龙头判定标准
"leader_criteria": {
    "absolute_leader_share": 0.30,  # 绝对龙头：份额>30%
    "oligarch_share": 0.10,         # 寡头之一：份额>10%
}
```

## 📝 注意事项

1. **数据来源**
   - 财务数据来自AKShare API
   - API可能不稳定，已加重试机制
   - 建议使用缓存减少API调用

2. **分析局限**
   - 产业链信息需要人工补充
   - 行业周期判断需要专业数据
   - 回本预测基于假设，不保证准确

3. **投资风险**
   - 本系统仅供参考
   - 不构成投资建议
   - 投资决策需自行承担风险
