# 决策记录 0004：行业雷达先于公司池

## 决策

机会发现拆成两个明确边界：

```text
行业雷达：只采集和核验行业级指标
  → 行业状态与机会类型
  → 通过门槛后建立有限公司池
  → 公司轻量数据、深度研究和模拟决策
```

`industry-radar` 阶段不加载公司池、不拉取全市场个股行情、财务、估值或公告全文。每个行业指标可以配置独立查询和来源顺序，复用交易所/公司披露、东方财富、AKShare、BaoStock 的统一路由；来源失败、字段缺失或返回空结果时继续切换，并保留完整尝试链。

## 配置边界

行业雷达配置只要求 `industry_id`、`display_name`、`as_of` 和 `state`，可选 `signals` 与 `radar_queries`。公司池是后续行业研究阶段的输入，不是行业雷达的必填字段。一个查询至少声明：

- `name`：行业指标名称，例如库存、价格、开工率或供给退出；
- `query`：传给统一数据源路由器的查询参数；
- `value_path`：从已选来源标准化结果中取值的显式路径；
- `source_names`：该指标的主备来源，可覆盖默认行业来源链；
- `required`：该指标失败时是否阻止本轮行业数据达到 `READY`。

系统只负责采集、保存时间截面和来源血缘，不把单个指标或静态配置自动升级为反转确认，更不直接生成买卖结论。

## 影响

- 资源消耗首先与行业指标数量相关，而不是与全市场公司数量线性相关；
- 行业雷达可以在没有公司池的情况下独立运行和审计；
- 公司池、产品经济学、生存分析、四维机会快照和模拟决策继续复用既有行业优先编排器；
- 没有足够行业证据时输出 `PARTIAL` 或 `INSUFFICIENT`，不为了进入公司研究而填充虚构指标。
