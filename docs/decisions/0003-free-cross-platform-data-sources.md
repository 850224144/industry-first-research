# 决策记录 0003：跨平台免费数据源

## 决策

首期不依赖 QMT 或任何券商终端。默认采用跨平台免费数据链路，并按字段配置主备顺序：

```text
交易所/公司原始披露：事实底座，优先核验
东方财富接口：行情、公开财务和市场数据补充
AKShare：行情、财务、指数、行业和期货的统一便捷采集入口
BaoStock：A 股历史行情和复权序列补充
期货合约规则、公告、结算和仓单：交易所公开资料优先，东方财富/AKShare 辅助采集
```

QMT 需要特定 Windows 本地环境和权限，不能作为 Mac 用户的基础依赖，因此从首期产品范围、安装要求、成本假设和验收标准中移除。未来如果需要在其他机器上使用 QMT，只能作为外部可选数据源，不得改变核心模型，也不得接入实盘凭证或自动下单。

## 主备切换规则

每类数据维护一个有序来源链，例如：

```text
公司事实/公告：交易所或公司披露 → 东方财富 → AKShare → BaoStock
A 股行情：交易所/东方财富 → AKShare → BaoStock
行业数据：交易所/协会/政府 → 东方财富 → AKShare
期货合约与仓单：交易所 → 东方财富 → AKShare
```

某来源发生连接失败、超时、限流、接口异常、空结果或关键字段不完整时，路由器自动尝试下一个来源。每一次尝试都记录来源、状态、错误原因、时间和最终选用来源；全部来源失败才输出 `INSUFFICIENT`，不得静默填充。

## 复用边界

- 东方财富和 AKShare 是便捷采集入口，不是最终事实源；关键数字必须保留接口、抓取时间、参数、版本，并回溯原始公告或正式统计。
- BaoStock 保留为 A 股历史行情补充，与东方财富、AKShare 组成备用链路，不覆盖港股、期货、公告和行业事实。
- 交易所和公司原始披露优先于聚合接口；来源冲突时保留双方数据，降低结论强度并记录裁决原因。
- 免费接口可能限流、改字段或暂时失效。适配器必须健康检查、缓存、重试、记录失败，并允许降级到本地快照或“数据不足”。
- 不把免费接口的“可获取”误认为“已核验”，也不因接口不可用使用静默默认值。

## 影响

- Mac 本地可以安装和运行基础数据链路，不需要 QMT；四类免费/公开来源可以按主备顺序协同工作。
- 首期数据依赖仍保持可插拔，未来可以增加其他免费来源或商业数据，但必须经过能力、质量、许可证和成本评审。
- 原有行业优先、少量公司深研和无自动交易边界不变。
