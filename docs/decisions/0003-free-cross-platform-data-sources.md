# 决策记录 0003：跨平台免费数据源

## 决策

首期不依赖 QMT 或任何券商终端。默认采用跨平台免费数据链路：

```text
公司/行业公开市场数据：AKShare
A 股历史行情备用：BaoStock
期货合约规则、公告、结算和仓单：交易所公开资料优先，AKShare 辅助采集
公司事实与财务口径：上交所、深交所、北交所、港交所、巨潮等原始公告/披露
```

QMT 需要特定 Windows 本地环境和权限，不能作为 Mac 用户的基础依赖，因此从首期产品范围、安装要求、成本假设和验收标准中移除。未来如果需要在其他机器上使用 QMT，只能作为外部可选数据源，不得改变核心模型，也不得接入实盘凭证或自动下单。

## 复用边界

- AKShare 是便捷采集入口，不是最终事实源；关键数字必须保留接口、抓取时间、参数、版本，并回溯原始公告或正式统计。
- BaoStock 只作为 A 股历史行情补充，不覆盖港股、期货、公告和行业事实。
- 交易所和公司原始披露优先于免费聚合接口；来源冲突时保留双方数据，降低结论强度并记录裁决原因。
- 免费接口可能限流、改字段或暂时失效。适配器必须健康检查、缓存、重试、记录失败，并允许降级到本地快照或“数据不足”。
- 不把免费接口的“可获取”误认为“已核验”，也不因接口不可用使用静默默认值。

## 影响

- Mac 本地可以安装和运行基础数据链路，不需要 QMT。
- 首期数据依赖仍保持可插拔，未来可以增加其他免费来源或商业数据，但必须经过能力、质量、许可证和成本评审。
- 原有行业优先、少量公司深研和无自动交易边界不变。
