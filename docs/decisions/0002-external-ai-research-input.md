# 决策记录 0002：外部网页 AI 研究输入层

## 状态

接受。首期采用人工粘贴，不调用豆包、腾讯元宝、DeepSeek 等网页产品的接口，也不自动化操作其网页。

## 背景

网页 AI 可以低成本帮助发现行业资料、公告链接、产业链关系、竞争对手和反证，但回答的来源、时间截面和可复现性不稳定。因此它适合做研究线索和资料整理，不适合成为关键事实的唯一依据。

## 规则

外部 AI 输入必须保存：

- 提供方和用户填写的模型/会话名称；
- 提问内容；
- 用户粘贴的完整回答或附件摘要；
- 获取时间；
- 回答中的来源链接；
- 系统提取的事实、观点、未知项和待核验项；
- 后续核验状态。

证据等级：

```text
A  官方公告、财报、交易所、公司正式资料
B  两个独立可靠来源交叉验证
C  网页 AI 回答中带来源的研究线索
D  无来源模型推测、传闻或用户未核验摘录
```

C 级只能进入线索池，不能单独支撑候选升级、目标价或模拟决策锁定。多个网页 AI 给出相同答案，也不能自动升级证据等级。

## 数据边界

本层只保存用户选择的研究输入和必要的来源元数据，不自动保存全市场网页内容，不把网页回答批量转成本地数据库。关键数字、公司边界、产品收入、债务、公告日期和行业状态必须在进入正式结论前用官方或交叉来源核验。

## 失败处理

当回答没有来源、来源失效、时间不明或不同网页 AI 互相矛盾时，系统将其标为 `UNVERIFIED`，保留为待核验线索，不静默合并为事实。网页产品不可用不影响本地研究流程；系统仍可使用已有证据、规则和最后锁定结论。
